## 触觉卡改版与 HD 试听（2026-11-02）

- 布局：同一排两张卡共用一个折叠状态（`hapticsRowOpen` / `systemRowOpen`）。单独收起一张会在旁边那张下面留空，所以改成整排一起收。声音缓冲移入“性能与兼容性”，两排各自左右对称。声音增益当天稍后改放 HD 触觉卡，见下一节。
- 对齐实测：1280×820 和 1080×720 两种窗口 × 默认/全收/全展三种状态，两排卡的 `y` 与 `height` 全部逐像素相同（触觉排 `268 → 84`，系统排 `84 → 344`）。
- HD 试听：`play_test_haptics()` 按 48 kHz 4 声道 float32 往手柄声卡的第 3、4 声道播三下 150 Hz 短脉冲（声道 1、2 静音）。真机确认手柄能感到三下；1.0× 与 2.0× 的强弱对比留待按钮进 App 后在界面里验。
- 打包：`sounddevice` 是惰性导入，PyInstaller 静态分析看不到，已加进 spec 的 `hiddenimports`；`--self-test` 也加了一句导入它，只验导入不枚举设备（没插手柄时本来就枚举不到）。源版自检退出码 `0`。

## HD 试一下冷启动无感的修复（2026-11-02）

- 现象：冷启动后连点三次 HD 的“试一下”都没有震感，日志每次都记成功、不报错；点一次普通震动之后，HD 就正常了，像被唤醒。
- 根因：输出报文 0x02 的第 1 字节 `0x02` 是 `UseRumbleNotHaptics`——手柄处于该模式时执行器归马达管，送进触觉声道的波形被忽略。`play_test_rumble` 结束时写的那条全零报文会把执行器交还给音频触觉（`protocol.py` 原有注释已写明），所以必须先点普通震动，HD 才有感觉。
- 修法：`play_test_haptics(device)` 在播波形前自己先写一条 `rumble_report(0)`。服务层为此开一个 HID 句柄，用完即关；句柄打不开（只读固件、设备被占）时仍照常播放，不拒绝。
- 测试：协议层 2 条（发了全零报文再播；无句柄也播），服务层 2 条（开—关句柄的顺序；打不开时 `device=None` 仍播放）。把修复临时撤掉复跑，确认这些测试会失败，不是恒真断言。

## HD 试听 1.0× 与 2.0× 分不出强弱（2026-11-02）

- 现象：修好冷启动无感之后，HD 倍率拖到 1.0× 和 2.0× 各试一次，手感差别很小。
- 根因：削顶，不是时长。波形振幅原为 `0.4`，旁边注释按“0.4 × 2.0 = 0.8 < 1.0”认为留足了余量，**漏算了 `speaker_gain`**。实际信号链是 `波形 × HD 倍率(1.0~2.0) × speaker_gain`，当时设备上是 `speaker_gain=7`（出厂默认 2，约再放大一倍）：1.0× 已达 ~0.8 接近满刻度，2.0× 达 ~1.6 被削平，两档都顶在天花板上。
- 修法：振幅 `0.4 → 0.25`，使最坏情况（2.0× × 增益 7）正好 1.00 满刻度不过头，1.0× 落在半程；单次脉冲 `0.18 s → 0.32 s`（总 0.98 s → 1.40 s），太短的脉冲在执行器完全起振前就结束，本身也会压缩强弱差。
- 新增测试把“HD 倍率 × speaker_gain 的最坏情况 ≤ 满刻度”固化，避免以后调振幅时再次踩回削顶。
- 注意：增益越高可分辨范围越窄。实测在增益 7 下仍能分辨（见下一节），想要余量更大可把声音增益调回出厂默认 2。

## 真机复测：HD 试听通过（2026-11-02 18:56）

- 冷启动后直接点 HD 的“试一下”即有震感，**不需要先点普通震动唤醒**——`UseRumbleNotHaptics` 的交还修复确认有效。
- 倍率对比：在 `speaker_gain=7` 下依次 1.00× / 2.00× / 1.60× 各试一次，用户确认强弱**能分辨**。振幅 0.25 + 单脉冲 0.32 s 的组合在最高增益档也留住了可分辨范围。
- 附带结论：接收器确实把 HD 倍率作用在音频触觉通路上，改倍率能改变实际震感，不只是写进配置。

## 配置页回报率一直“已停止”（2026-11-02 19:04）

- 现象：配置页的回报率卡恒为“已停止 / — Hz”、曲线空白；设备页同样的卡却有数。加长截图等待时间无效。
- 根因：`Main.qml` 的 `rateActive` 条件是 `win.visible && visibility !== Minimized && win.page === 1`——第三个条件把采样限制在设备页。此前把它读成“只跟窗口可见绑定”，是只看了换行前半句导致的误判，而且当时没有测试覆盖这个属性，所以错误判断没被挡住。
- 修法：条件改为页 0 或页 1 都采样（关于页不采），并补上直接断言 `rateActive` 随页变化的测试。
